# Tetris Java 🎮

Un clásico juego de Tetris desarrollado en Java. Este proyecto fue creado y estructurado utilizando el entorno de desarrollo IntelliJ IDEA.

Es un proyecto ideal para entender la lógica de videojuegos bidimensionales, el manejo de ciclos de juego (game loops) y la renderización de gráficos en Java.

## ✨ Características
* Mecánica clásica de Tetris: caída de piezas, rotación y eliminación de líneas completas.
* Interfaz gráfica limpia ejecutada directamente desde el entorno de desarrollo.
* Control de juego mediante el teclado.

## 🚀 Requisitos e Instalación

Para jugar o revisar el código en tu computadora, asegúrate de tener lo siguiente:

1. Java JDK (versión 11 o superior recomendada).
2. IntelliJ IDEA (versión Community o Ultimate).

### Pasos para ejecutarlo:

1. Clona el repositorio (o descarga el código en formato ZIP):
   git clone https://github.com/TioAnon/tetris-JAVA.git

2. Abre IntelliJ IDEA.
3. Selecciona File > Open... y busca la carpeta donde descargaste el proyecto.
4. Espera a que IntelliJ indexe los archivos.
5. Busca el archivo principal que contiene el método main (por ejemplo, Main.java o Game.java).
6. Haz clic derecho sobre el archivo y selecciona Run 'Main' (o presiona Shift + F10).

## 🎮 Controles del Juego

* ⬅️ / ➡️ : Mover la pieza a la izquierda / derecha.
* ⬆️ : Rotar la pieza.
* ⬇️ : Caída rápida.
* ⌨️ Espacio : Pausar el juego / Caída instantánea.
